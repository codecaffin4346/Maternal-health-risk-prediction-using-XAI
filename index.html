    Dataset Information

    The UCI Maternal Health Risk Dataset (Ahmed et al.) was collected using IoT-based risk monitoring systems across rural and urban areas of Bangladesh. It contains six clinical measurements from pregnant women and is labelled with three risk levels by medical professionals.

    📦 1,014 samples 🟢 Low: 406 (40.0%) 🟡 Mid: 336 (33.1%) 🔴 High: 272 (26.8%) 🔢 Features: 6 ⚖️ SMOTE balancing: Yes 🔁 CV: 5-fold stratified

    🔬 How Explainable AI Works

    Understanding the science behind the predictions — from Random Forest to SHAP values.

    🔄 End-to-End Prediction Pipeline

    1

    Input Collection

    6 clinical vitals entered: Age, Systolic BP, Diastolic BP, Blood Sugar, Body Temperature, Heart Rate.

    2

    Random Forest Inference

    10 decision trees each independently process the inputs. Each tree traverses from root to leaf based on feature thresholds, producing a class probability distribution [P(Low), P(Mid), P(High)].

    3

    Ensemble Aggregation

    Probabilities from all 10 trees are averaged. The class with the highest average probability becomes the predicted risk level.

    4

    TreeSHAP Computation (XAI Layer)

    For each tree, we track the path taken and measure how much each feature split shifts the expected risk score from the parent node to the child node. These path contributions are averaged across all trees to produce the final SHAP value per feature.

    5

    Output Generation

    Risk class, confidence probabilities, SHAP waterfall chart, clinical summary, and personalised recommendations are rendered.

    🌲 What is Random Forest?

    A Random Forest is an ensemble of decision trees. Each tree is trained on a random subset of the training data and a random subset of features — this reduces overfitting and improves generalisation.

    For classification, each tree votes for a class. The majority vote (or averaged probability) becomes the final prediction.

    • Handles non-linear relationships well
    • Robust to outliers and noisy data
    • Naturally provides feature importance scores
    • No need for feature scaling or normalisation
    • Achieves 93–95% accuracy on the maternal health dataset

    🔍 What are SHAP Values?

    SHAP (SHapley Additive exPlanations) is a game-theory method that assigns each feature a "credit" for the prediction — fairly distributed based on how much each feature contributed to shifting the output from the baseline.

    The baseline is the average prediction across all training samples. SHAP values explain the deviation of a specific prediction from that baseline.

    • Positive SHAP → feature pushes prediction toward higher risk
    • Negative SHAP → feature reduces predicted risk
    • All SHAP values sum to the total deviation from baseline
    • TreeSHAP computes exact values in polynomial time for tree models

    ⚠️ Known Limitations & Responsible Use

    • The training dataset (n=1,014) is from Bangladesh — generalisability to other populations requires validation
    • Only 6 features are used; many clinically relevant factors (e.g., previous obstetric history, BMI, haemoglobin) are absent
    • Single time-point measurements — does not capture pregnancy progression over time
    • Class imbalance (fewer high-risk cases) is handled via SMOTE, but may slightly overestimate mid-risk boundaries
    • This is a research prototype and must NOT be used as a standalone clinical diagnostic tool
    • All predictions must be reviewed and verified by qualified healthcare professionals
